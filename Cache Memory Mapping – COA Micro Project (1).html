What is a cache?

Main memory is big but slow. The CPU keeps a small, fast copy of recently used data in the cache. Memory is split into blocks, and the cache has lines that each hold one block.

Hit
The data is already in the cache. Fast.
Miss
The data is not in the cache, so it is loaded from memory. Slow.
Hit ratio
hits ÷ total accesses

Think of your desk (cache) and a library (main memory). Books already on the desk are a hit. Walking to the library is a miss.

Three ways to map a block

Mapping decides which cache line a memory block is allowed to use.

Direct
Each block has exactly one possible line.
✔ Simple and fast
✘ Many clashes
Associative
A block can go in any line.
✔ Fewest clashes
✘ Costly to search
Set-associative
A block goes into one fixed set and can use any line (way) inside it.
✔ Balanced middle option

When a set is full

A replacement policy chooses the victim. FIFO removes the oldest block. LRU removes the block unused for the longest time.

The only formulas you need

Block numberaddress ÷ block size

Direct: sets = lines. Associative: sets = 1. Set-associative: sets = lines ÷ ways.

Quick check

Why do addresses 0 and 16 keep missing in a 4-line direct cache (block size 4)?Both are in blocks that map to line 0 (block 0 and block 4, 4 mod 4 = 0), so each one replaces the other every time.
Which mapping has the fewest misses, and what is the cost?Associative mapping, because a block can go anywhere. The cost is that the hardware must search every line.
What is the tag for?Many blocks share one line, so the tag tells which block is currently stored there.
